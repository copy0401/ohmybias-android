0.3.4 — punctuation pairing
• Half-width brackets now pair too: ( [ { produce () [] {} with the caret in the middle, and so does the double quote
• The single quote is deliberately left out, so don't and Daniel's stay intact
• Fixed symbol keys not pairing: a 【 typed by code paired, but the same character tapped on the symbol page, the symbol panel or a key swipe did not — both paths behave the same now
• Turn it off with "auto-close paired punctuation" in settings
